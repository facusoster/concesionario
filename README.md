# concesionario

Sistema de Gestión para Agencia de Autos (Trabajo Práctico Parcial).

## Uso

Abrí `/home/runner/work/concesionario/concesionario/index.html` en tu navegador.

### Funcionalidades

- Alta de vehículos (marca, modelo, año, precio, tipo y estado)
- Listado con búsqueda y filtro por estado
- Eliminación de vehículos
- Resumen de cantidad y valor total
- Persistencia en `localStorage`
